This work investigates **Processing-in-Memory (PIM)** and **FPGA** acceleration for latency-sensitive deep neural network inference on edge servers, motivated by real-time applications such as UAV-assisted search and rescue.

### Key Contributions

- Analyzed inference latency, computational acceleration, and energy consumption using representative LeNet-5 workloads.
- Reported up to **92x speedup** for the evaluated simulated PIM configuration relative to CPU execution.
- Reported **0.02 ms inference latency** for an FPGA configuration in the published experiments.
- Examined **Age of Information (AoI)** as a measure of freshness for data processed by edge servers.

**Authors:** Ali Suvizi, Suresh Subramaniam, Tian Lan, and Guru Venkataramani.
